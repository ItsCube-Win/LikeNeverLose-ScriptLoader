# 🔫 Neverlose Arsenal Script

A powerful and feature-rich Roblox script for **Arsenal**, built on the NeverLose UI library. It includes Aimbot, Silent Aim, Auto Fire, ESP, and Bunny Hop.

> ⚠️ **This version is experimental and will no longer receive updates.**  
> Future improvements and features will be available in a separate, maintained release.

## ✨ Features

### 🎯 Aimbot
- Smooth aiming with adjustable smoothing and prediction
- Customizable FOV circle (color, target color, rainbow mode, thickness)
- Multiple aim parts (Head, Torso, Arms, Legs)
- Sticky aim, team check, wall check, health check

### 🤫 Silent Aim
- Shoots at targets without moving your camera
- Separate FOV circle with full customization
- Wall check and visibility check

### 🔥 Auto Fire
- Automatically shoots when an enemy is in FOV
- Adjustable shoot delay, range, and prediction
- Prioritize closest target or by crosshair distance
- Customizable FOV circle (color, rainbow, thickness)

### 👁️ ESP (Extra Sensory Perception)
- **Box ESP**: Corner or Full box with color picker
- **Tracer ESP**: Lines from screen origin to enemies
- **Health Bar**: Bar, text, or both
- **Name ESP**: Display player names
- **Snaplines**: Lines from bottom of screen to enemies
- **Chams**: Highlight enemies with fill and outline colors
- **Rainbow Mode**: Cycle through colors for all ESP elements
- Adjustable max distance, thickness, and team checks

### 🏃 Movement
- **Speed Bhop**: Gain speed while bunny hopping (configurable boost and cap)
- **Auto Bhop**: Automatically jumps while holding movement keys

### ⚙️ Other
- Fully configurable via NeverLose UI
- Settings saved automatically in `ArsenalConfigs` folder
- Watermark with ping display
- Customizable notification system

## 📦 Installation

1. Use a Roblox executor that supports the NeverLose UI library (e.g., **Fluxus**, **Delta**, **Codex**, **Hydrogen**).
2. Copy the script from the [ScriptBlox](https://github.com/itscube_win/neverlose-arsenal/releases) or from the raw source.
3. Paste the script into your executor.
4. Attach and execute.
5. Press `Insert` to open/close the GUI.

## 🎮 Usage

- Navigate through tabs: **Aimbot**, **Visuals**, **Misc**, **About**.
- Toggle features on/off and adjust sliders/colors to your preference.
- All settings are saved automatically between sessions.
